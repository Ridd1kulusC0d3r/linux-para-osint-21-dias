# Créditos e atribuição

## Curso original

Este repositório é um **material de estudo derivado** do curso
**"Linux for OSINT. 21-day course for beginners"**, criado por
**cipher387 / Cyber Detective**.

- Repositório original: <https://github.com/cipher387/linux-for-OSINT-21-day>
- PDF do curso: <https://github.com/cipher387/linux-for-OSINT-21-day/blob/main/Linux%20for%20OSINT.pdf>
- Site do autor: <https://cybdetective.com>
- Curso irmão: [Python for OSINT. 21-day course for beginners](https://github.com/cipher387/python-for-OSINT-21-days)

O curso original é distribuído sob licença MIT. O aviso de copyright original
está preservado em [`LICENSE-ORIGINAL`](LICENSE-ORIGINAL).

## O que foi aproveitado e o que é novo

| Parte | Origem |
|---|---|
| Sequência dos 21 temas e os comandos ensinados em cada dia | Curso original (cipher387) |
| Textos explicativos, em português | Escritos do zero para este repositório — **não** são tradução do PDF |
| História "Operação Vazante", personagens e desafios com flag | Novos |
| Evidências fictícias em `desafio/` e as fábricas em `ferramentas/fabrica/` | Novas |
| `equivalente.py` (ponte para Python stdlib), versões brazucas, seções de ética | Novos |
| Notebooks Colab, devcontainer, CI, site e checador de flags | Novos |

Para estudar o conteúdo original, leia o PDF do autor — ele é a fonte
primária deste material. Se você gostou deste repositório, **dê uma estrela
no original também**.

## Ficção

Todas as pessoas, empresas, domínios, e-mails e telefones da Operação Vazante
